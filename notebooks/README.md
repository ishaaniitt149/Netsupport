# Notebooks & Databricks Workflows

This directory contains analytical workflows, feature engineering prototypes, and PySpark exploration notebooks for Databricks.

## Planned Notebooks:
1. `01_telemetry_feature_engineering.py`: Rolling window feature calculations (CRC slope, optical power drift, memory leak index).
2. `02_random_forest_training.py`: Supervised model training using scikit-learn and MLflow tracking.
3. `03_dashboard_reporting_queries.sql`: Databricks AI/BI SQL queries for MTTR, MTTD, and risk leaderboards.
